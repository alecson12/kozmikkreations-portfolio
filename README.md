# Kozmik Kreations — Graphic Design Portfolio

An interactive universe: every project is a planet. Built with Vite + React + Tailwind,
the same setup as the other three sites.

## See it on your computer

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5175

## Where things are

| What | Where |
| --- | --- |
| All text (home, about, contact, email, links) | `src/content/site.js` |
| The projects: titles, slide order, planet look | `src/content/projects.js` |
| Your original artwork (never changed by the site) | `Projects/` |
| Your logo files, as supplied | `KozmikLogos/` (copied to `public/brand/`) |
| Web-sized copies the site loads | `public/media/` (made automatically) |

## Project stories ("About this project")

Every project page shows a short story and a few facts. All of it lives in one file:
`src/content/projects.js`. Each project block can have:

| Field | What it is | Shown as |
|---|---|---|
| `title`, `kind` | name and category | page title, "Category" |
| `client` | client or brand | "Client" |
| `year` | when it was made | "Year" |
| `role` | what you did | "Role" |
| `tools` | software used | "Tools" |
| `story` | two to four sentences in your own voice | the paragraph |
| `storySource` | where the story came from (`'behance'` or `'artwork'`) | never shown |
| `isPlaceholder` | `true` = the story still needs your own words | never shown |

Leave out `client`, `year`, `role` or `tools` and that line simply does not appear.

**Stories that still need you:** search `projects.js` for `isPlaceholder: true`. Those were written
only from what the artwork itself shows. Rewrite the `story`, then set `isPlaceholder: false`.

**Adding a project with its story:** follow "Add or change a project" below and include the
`story` line (and any facts you know) in the new block.

## Sound

- **Effects** (hover, click, page change) are generated by the site itself. There are no sound files.
  The code is in `src/lib/audio.js` (the sounds) and `src/lib/sfx.js` (which controls make which sound).
- **Ambience** is a space soundscape the site generates live (also in `src/lib/audio.js`). It is the
  background sound. It never starts by itself; the visitor presses play in the sound panel.
- **Mixtape** is Spotify's own player, docked in the corner when the visitor opens it from the
  sound panel. To change the playlist, open one on Spotify → Share → Embed, and paste the
  `https://open.spotify.com/embed/…` address into `audio.mixtape.embed` in `src/content/site.js`.
- **Your own music file** (optional) replaces the generated ambience: put one file in
  `public/audio/` and set `audio.music.file` in `site.js` to its name.
- **Levels and defaults** are in the same `audio` block of `site.js`: `sfxLevel` (how strong the
  effects are), `ambient.level` (how strong the ambience is), `music.level` (how loud a music file sits) and `defaults` (what a first-time visitor starts with).
- Visitors control everything from the speaker button in the navigation, and their choice is remembered.

## Add or change a project

1. Put the images / videos in a folder inside `Projects/`.
2. Open `src/content/projects.js`, copy one of the blocks and fill it in.
   `slides` is the list of files **in the order they should appear**.
   `layout` is `'carousel'` (one slide at a time, for carousel posts) or
   `'gallery'` (everything on one page, for poster sets and single prints).
3. Run:

```bash
npm run media
```

   That makes the web-sized copies and tells you if a file is missing or was left out.
   Videos need one extra tool the first time: `npm install --no-save ffmpeg-static`.

Nothing is cropped or redrawn. Images are only resized and saved as high-quality WebP;
videos are re-encoded at web size with their sound.

## Publish

The repo is ready for GitHub Pages (`.github/workflows/deploy.yml`). The site works
under any repo name, so nothing needs editing first.

1. Create an empty repo on GitHub.
2. `git remote add origin https://github.com/alecson12/<repo-name>.git`
3. `git push -u origin main`
4. If the first run fails, set Settings → Pages → Source to **GitHub Actions** and re-run.

`Projects/` (the 827 MB of originals) is deliberately not uploaded; keep your own backup of it.
